<p>
 <a href="https://support.discord.com/hc/en-us/articles/14078261239831-Clarifying-Server-Types">
  Discoverable Servers
 </a>
 are the most public spaces on Discord, with at least 1,000 members. Their admins chose to list them in Server Discovery so anyone can join them, no invite link needed.
</p>
<p>
 Discussions in Discoverable Servers will soon be easier to find when you search the web, so you can find the answer you’re looking for and step straight into the conversation on Discord. Admins and members can decide if and how their content is shared, and those controls start rolling out today, ahead of any changes.
</p>
<p>
 <strong>
  TL;DR:
 </strong>
</p>
<ul role="list">
 <li>
  <strong>
   Help people find your community with Server Web Pages.
  </strong>
  A Server Web Page is a page on the web that describes a Discoverable Server, so people can decide whether they want to join. Starting November 16, 2026, all Discoverable Servers will have a Server Web Page. These pages may also display summaries of discussions happening in public channels (those visible to everyone in the server), to give a better sense of what people are talking about. Some messages from public channels may show on Server Web Pages and in web search beginning in mid-December 2026. The rollout is gradual, so it may be a few weeks before the first messages start appearing on the web.
 </li>
 <li>
  <strong>
   Server admins can opt channels out starting today, before anything goes live on November 16, 2026.
  </strong>
  Controls for admins are in Server Settings &gt; Web Presence. You can choose which channels take part, or opt all channels out. If you don’t change anything, public channels stay on, and your Server Web Page goes live on November 16, 2026, if you don't already have one.
 </li>
 <li>
  <strong>
   Users have control over whether their messages are shown.
  </strong>
  If you'd rather your messages weren't shown, you can turn that off starting today in
  <a href="https://discord.com/settings/data-and-privacy">
   User Settings &gt; Data and Privacy
  </a>
  , before messages start rolling out in mid-December 2026 (or anytime after). One setting covers Channel Messages in every Discoverable Server. Channel Summaries are generated separately, from broader channel topics, and will still appear on Server Web Pages unless admins choose to turn them off. Usernames and avatars won't be shown alongside messages on Server Web Pages
 </li>
 <li>
  <strong>
   Private servers, DMs, and GDMs are always private and not included in these changes.
  </strong>
  These changes are limited to Discoverable Servers.
 </li>
</ul>
